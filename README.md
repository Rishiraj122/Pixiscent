# Pixiscent

Practice computer vision from scratch in the browser: 70 problems across 8 modules, from pixels and histograms to classification and object detection. Code runs in the browser with Skulpt (Python 3).

- Hosted on GitHub Pages (`index.html`).
- Players, progress sync, the leaderboard and weekly contests use Supabase. `supabase/schema.sql` sets up the database; the site only calls the functions defined there.
